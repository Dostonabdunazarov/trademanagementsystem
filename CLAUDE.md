## Claude Code

- Правила, привязанные к путям, лежат в `.claude/rules/`. Они подгружаются автоматически, когда работа касается соответствующих файлов.
- Скиллы проекта:
  - `/verify` — полный прогон проверок;
  - `/new-feature` — сквозная фича: CQRS → эндпоинт → хук → UI → i18n;
  - `/ef-migration` — безопасная миграция;
  - `/tenant-audit` — проверка скоупинга по компании, филиалу и роли;
  - `/fix-audit-item` — исправление пункта из `AUDIT_2026-09-29.md`.
- Сабагенты:
  - `tenant-security-reviewer` — ревью изменений API на IDOR и роли;
  - `ledger-logic-reviewer` — ревью изменений в документах, складе, балансах и отчётах.
- Папка `.agents/agents/` содержит исторические спецификации для первоначального скаффолдинга. Они **устарели**, источник истины — код и `docs/`.
