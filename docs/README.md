# Документация TradeMS

Техническая документация системы управления торговлей **TradeMS** — .NET 10 (Clean Architecture) + React 19 + PostgreSQL.

Общий обзор проекта и быстрый старт — в [корневом README](../README.md). Здесь собраны подробные технические разделы.

## Разделы

| Раздел | О чём |
|---|---|
| [Архитектура](architecture.md) | Слои Clean Architecture, поток запроса, CQRS/MediatR, ключевые каталоги |
| [API](api.md) | Полный список HTTP-эндпоинтов, требования к авторизации, параметры |
| [База данных](database.md) | Сущности, схема таблиц, индексы, оптимистичная блокировка, миграции |
| [Роли и безопасность](security.md) | JWT, роли, политики доступа, мультитенантность и филиалы, аудит, блокировка |
| [Бизнес-логика документов](documents.md) | Типы документов, статусы, движение склада и балансов при проведении/отмене |
| [Фронтенд](frontend.md) | Структура React-приложения, роутинг, стор, API-слой, i18n, темы |
| [Разработка и деплой](development.md) | Локальный запуск, переменные окружения, тесты, Docker, CI/CD |

> Документация отражает состояние кода на момент написания. Если файл называет конкретный эндпоинт, поле или флаг — сверяйтесь с исходником по указанным путям.
